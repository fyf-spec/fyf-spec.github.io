# 第一到六章重要概念不定项选择题

说明：每题至少有一个正确选项，可能有多个正确选项。答案后的“思路”只保留判断该题所需的关键依据。

---

## 第一章：计算机网络和因特网

### 概念 1：互联网的组成与服务视角

**1.1（不定项）从“螺母和螺栓”视角看，互联网包含哪些组成部分？**

A. 端系统或主机  
B. 通信链路  
C. 分组交换设备  
D. 只运行在服务器上的单一中心程序  

答案：A、B、C  
思路：互联网由端系统、链路、路由器/交换机和协议组成，不是一个中心程序。

**1.2（不定项）从服务视角看，互联网可以理解为？**

A. 为分布式应用提供通信服务的基础设施  
B. 只负责网页浏览，不支持其他应用  
C. 应用通过 API 使用底层网络服务  
D. 应用开发者通常不直接控制核心路由器  

答案：A、C、D  
思路：服务视角强调互联网为 Web、邮件、视频、游戏等应用提供通信能力。

### 概念 2：协议、标准与分层

**2.1（不定项）一个网络协议通常规定哪些内容？**

A. 报文格式  
B. 报文交换顺序  
C. 收到报文或发生事件时的动作  
D. 所有物理介质的制造材料  

答案：A、B、C  
思路：协议的核心是格式、顺序和动作。

**2.2（不定项）关于协议分层，下列说法正确的是？**

A. 分层让每层只关注本层服务和相邻层接口  
B. 分层允许某层内部实现改变而尽量不影响其他层  
C. 分层没有任何代价  
D. 某些功能可能在多层重复出现，例如错误检测  

答案：A、B、D  
思路：分层简化系统，但也可能造成信息隔离和功能重复。

### 概念 3：网络边缘、接入网与物理介质

**3.1（不定项）关于网络边缘和端系统，下列说法正确的是？**

A. 网络应用主要运行在端系统中  
B. 客户端通常主动发起请求  
C. 服务器通常等待请求并提供服务  
D. 网络核心路由器通常运行用户 Web 应用  

答案：A、B、C  
思路：网络边缘运行应用，核心主要负责转发。

**3.2（不定项）关于接入网和物理介质，下列说法正确的是？**

A. HFC 中多个家庭可能共享电缆分配网络  
B. DSL 使用已有电话线，并用不同频段区分语音和数据  
C. 光纤速率高、误码率低、抗电磁干扰  
D. 提高链路带宽一定会提高信号传播速度  

答案：A、B、C  
思路：带宽影响传输时延，不等于改变介质中的传播速度。

### 概念 4：分组交换、转发、路由与存储转发

**4.1（不定项）关于转发和路由，下列说法正确的是？**

A. 转发是单台路由器本地动作  
B. 路由是全网范围内路径选择问题  
C. 转发表连接控制平面和数据平面  
D. 转发和路由是完全相同的概念  

答案：A、B、C  
思路：路由算路径，转发按表逐包选择输出端口。

**4.2（不定项）关于存储转发和排队，下列说法正确的是？**

A. 路由器通常完整接收一个分组后才转发该分组  
B. 分组长度为 L、链路速率为 R 时，传输时延为 L/R  
C. 输出链路忙时，分组可能排队  
D. 缓冲区无限大时永远不会有排队时延  

答案：A、B、C  
思路：排队来自到达速率超过服务速率；缓冲区大小影响丢包，不消除排队。

### 概念 5：电路交换、分组交换与统计复用

**5.1（不定项）关于电路交换，下列说法正确的是？**

A. 通信前通常需要建立连接  
B. 会为连接预留端到端资源  
C. 连接空闲时预留资源也不能被其他连接使用  
D. 特别适合突发性强的数据业务，因此互联网核心主要采用电路交换  

答案：A、B、C  
思路：电路交换性能稳定但资源利用率可能低。

**5.2（不定项）关于分组交换，下列说法正确的是？**

A. 不为每个会话预留固定资源  
B. 依赖统计复用提高资源利用率  
C. 可能产生排队、拥塞和丢包  
D. 在任何情况下都比电路交换提供更稳定的时延保证  

答案：A、B、C  
思路：分组交换适合突发流量，但不天然保证固定时延。

### 概念 6：时延、丢包、吞吐量与安全

**6.1（不定项）节点时延包括哪些部分？**

A. 处理时延  
B. 排队时延  
C. 传输时延  
D. 传播时延  

答案：A、B、C、D  
思路：节点总时延为处理、排队、传输和传播之和。

**6.2（不定项）关于网络安全，下列说法正确的是？**

A. 分组嗅探可能泄露明文内容  
B. 源 IP 地址可以被伪造，因此不能单独作为身份认证依据  
C. DDoS 攻击会影响服务可用性  
D. 安全问题只需要应用层解决，其他层无关  

答案：A、B、C  
思路：安全贯穿多层，涉及认证、加密、完整性、访问控制和过滤。

## 第二章：应用层

### 概念 7：应用架构、进程通信与套接字

**7.1（不定项）关于客户端-服务器架构，下列说法正确的是？**

A. 服务器通常始终在线  
B. 客户端通常主动发起请求  
C. 客户端之间通常不直接通信  
D. 服务器一定只能部署在一台主机上  

答案：A、B、C  
思路：服务器可以部署在数据中心集群中，不限一台主机。

**7.2（不定项）定位一个网络应用进程通常需要哪些信息？**

A. 主机 IP 地址  
B. 端口号  
C. 物理链路长度  
D. 应用进程使用的传输协议  

答案：A、B、D  
思路：IP 定位主机，端口定位进程，协议类型影响 socket 分解。

### 概念 8：应用对传输服务的需求与 TCP/UDP/TLS

**8.1（不定项）关于 TCP 和 UDP 对应用的服务，下列说法正确的是？**

A. TCP 提供可靠传输、流量控制和拥塞控制  
B. UDP 提供无连接数据报服务  
C. TCP 和 UDP 都内置加密  
D. UDP 不提供可靠性，但应用可在 UDP 之上自行实现可靠机制  

答案：A、B、D  
思路：普通 TCP/UDP 不加密，安全通常由 TLS 或应用机制提供。

**8.2（不定项）哪些应用通常强烈需要数据完整性？**

A. 文件传输  
B. 电子邮件  
C. 金融交易  
D. 可容忍少量丢包的实时音频  

答案：A、B、C  
思路：实时音频更看重时延，可在一定程度上容忍损失。

### 概念 9：HTTP 连接、请求响应与状态码

**9.1（不定项）关于非持久 HTTP 与持久 HTTP，下列说法正确的是？**

A. 非持久 HTTP 通常每个对象使用一个 TCP 连接  
B. 持久 HTTP 可在同一 TCP 连接上传输多个对象  
C. 非持久 HTTP 完全不需要 TCP 连接建立  
D. 持久 HTTP 可以减少重复握手带来的 RTT 开销  

答案：A、B、D  
思路：HTTP 通常运行在 TCP 上；持久连接复用 TCP 连接。

**9.2（不定项）关于 HTTP 响应，下列说法正确的是？**

A. `200 OK` 表示请求成功  
B. `404 Not Found` 表示对象不存在  
C. `304 Not Modified` 通常不返回对象主体  
D. `Date` 首部表示对象最后修改时间  

答案：A、B、C  
思路：对象最后修改时间是 `Last-Modified`，`Date` 是响应生成时间。

### 概念 10：Cookie、Web 缓存、条件 GET 与 HTTP/2/3

**10.1（不定项）关于 Cookie，下列说法正确的是？**

A. 服务器可通过 `Set-Cookie` 设置标识  
B. 浏览器后续请求可携带 `Cookie` 首部  
C. Cookie 可用于登录状态和购物车  
D. Cookie 完全不会带来隐私问题  

答案：A、B、C  
思路：Cookie 可实现状态，也可能被用于跟踪。

**10.2（不定项）关于 Web 缓存和条件 GET，下列说法正确的是？**

A. 缓存命中可减少访问源服务器的次数  
B. 条件 GET 可用 `If-Modified-Since` 验证缓存副本  
C. 对象未修改时，服务器可返回 `304 Not Modified`  
D. Web 缓存只会增加接入链路流量  

答案：A、B、C  
思路：缓存的目标之一就是减少响应时间和接入链路流量。

### 概念 11：DNS 层次结构、缓存与资源记录

**11.1（不定项）DNS 的主要功能包括？**

A. 主机名到 IP 地址转换  
B. 通过 MX 记录定位邮件服务器  
C. 通过 CNAME 支持主机别名  
D. 为 TCP 提供可靠传输  

答案：A、B、C  
思路：DNS 是应用层名称系统，不负责 TCP 可靠性。

**11.2（不定项）关于 DNS 缓存和查询，下列说法正确的是？**

A. 本地 DNS 服务器通常是主机查询 DNS 的第一跳  
B. 缓存记录有 TTL  
C. 缓存能降低解析时延和上层服务器负载  
D. DNS 集中在一台全球服务器上更可靠、更可扩展  

答案：A、B、C  
思路：DNS 采用分布式层次结构，集中式会有单点故障和规模瓶颈。

### 概念 12：电子邮件、P2P、BitTorrent、DASH 与 CDN

**12.1（不定项）关于电子邮件协议，下列说法正确的是？**

A. SMTP 用于邮件服务器之间推送邮件  
B. IMAP/POP/HTTP 可用于用户读取邮件  
C. SMTP 通常使用 TCP  
D. SMTP 主要用于浏览器获取网页对象  

答案：A、B、C  
思路：网页对象获取是 HTTP 的职责。

**12.2（不定项）关于 P2P、BitTorrent、DASH 和 CDN，下列说法正确的是？**

A. P2P 中 peer 既可下载也可上传  
B. BitTorrent 的稀缺优先有助于避免某些块消失  
C. DASH 允许客户端根据网络状况选择不同码率版本  
D. CDN 的目标之一是把内容靠近用户  

答案：A、B、C、D  
思路：这些机制都围绕扩展性、吞吐、时延和内容分发优化。

### 概念 13：Socket 编程与 WebServer 实验

**13.1（不定项）TCP 服务器通常涉及哪些 socket 或调用？**

A. welcome socket 监听端口  
B. `accept()` 返回 connection socket  
C. connection socket 专门服务某个客户端连接  
D. 每次发送 TCP 数据都必须显式指定目的 IP 和端口  

答案：A、B、C  
思路：TCP 连接建立后使用字节流 socket，不需每次指定目的地址。

**13.2（不定项）Lab2 简单 Web 服务器需要完成哪些工作？**

A. 接收 HTTP 请求  
B. 解析请求文件路径  
C. 文件存在时返回包含文件的 HTTP 响应  
D. 文件不存在时返回 404 Not Found  

答案：A、B、C、D  
思路：实验核心是 TCP 接收、HTTP 解析、文件读取和错误响应。

## 第三章：传输层

### 概念 14：传输层服务、多路复用与多路分解

**14.1（不定项）传输层主要把网络层的主机到主机通信扩展为？**

A. 进程到进程通信  
B. 端口到端口的逻辑交付  
C. 直接决定全球路由路径  
D. 可向应用提供 TCP 或 UDP 等服务  

答案：A、B、D  
思路：路径选择属于网络层控制平面，不是传输层主要职责。

**14.2（不定项）关于多路分解，下列说法正确的是？**

A. UDP 接收端主要根据目的 IP 和目的端口交付到 socket  
B. TCP 连接通常由四元组标识  
C. 多个不同客户端可以同时连接服务器的 80 端口  
D. TCP 和 UDP 都只看目的端口，行为完全相同  

答案：A、B、C  
思路：TCP 使用源/目的 IP 与端口组成的四元组区分连接。

### 概念 15：UDP 与校验和

**15.1（不定项）UDP 的特点包括？**

A. 无连接  
B. 不保证可靠交付  
C. 无拥塞控制  
D. 保证有序交付  

答案：A、B、C  
思路：UDP 是轻量数据报服务，不保证可靠、有序。

**15.2（不定项）关于 UDP 校验和，下列说法正确的是？**

A. 用于检测传输中的比特错误  
B. 使用反码求和思想  
C. 匹配时表示绝对不可能有错误  
D. 检测能力通常弱于 CRC  

答案：A、B、D  
思路：校验和匹配只能说明未检测到错误，仍可能漏检。

### 概念 16：可靠数据传输 rdt 的机制

**16.1（不定项）可靠数据传输通常需要哪些机制？**

A. checksum  
B. ACK/NAK 或重复 ACK  
C. 序列号  
D. 定时器和重传  

答案：A、B、C、D  
思路：分别处理比特错误、确认反馈、重复分组和丢包。

**16.2（不定项）关于 rdt 演进，下列说法正确的是？**

A. rdt 1.0 假设信道完全可靠  
B. rdt 2.0 处理比特错误  
C. rdt 2.1 引入序列号以处理 ACK/NAK 损坏导致的重复问题  
D. rdt 3.0 使用定时器处理分组或 ACK 丢失  

答案：A、B、C、D  
思路：rdt 每一版都对应更弱的底层信道假设。

### 概念 17：停止-等待、流水线、GBN 与 SR

**17.1（不定项）关于停止-等待和流水线协议，下列说法正确的是？**

A. 停止-等待每次最多一个未确认分组在途  
B. RTT 很大时停止-等待链路利用率可能很低  
C. 流水线允许多个未确认分组同时在途  
D. 流水线不需要更大的序列号空间  

答案：A、B、C  
思路：流水线提高利用率，但需要窗口、缓冲和更大序号空间。

**17.2（不定项）关于 GBN 和 SR，下列说法正确的是？**

A. GBN 使用累积 ACK  
B. GBN 接收方通常丢弃乱序分组  
C. SR 对正确收到的分组单独 ACK 并缓存乱序分组  
D. SR 窗口可任意大，不受序号空间限制  

答案：A、B、C  
思路：SR 为避免新旧序号混淆，需要满足窗口与序号空间约束。

### 概念 18：TCP 序列号、确认号、RTT 与超时

**18.1（不定项）关于 TCP 序列号和确认号，下列说法正确的是？**

A. TCP 是字节流协议，序列号按字节编号  
B. ACK 号通常表示接收方期望的下一个字节序号  
C. TCP ACK 是累积确认思想  
D. TCP 序列号按报文段个数编号而不是字节编号  

答案：A、B、C  
思路：TCP 序列号标识字节流中的字节位置。

**18.2（不定项）关于 TCP 超时估计，下列说法正确的是？**

A. EstimatedRTT 通常用 SampleRTT 平滑更新  
B. DevRTT 反映 RTT 波动  
C. TimeoutInterval 应考虑 EstimatedRTT 和 DevRTT  
D. 超时时间越小越好，永远不会造成问题  

答案：A、B、C  
思路：过小的超时会导致不必要重传；过大则恢复慢。

### 概念 19：TCP 流量控制、连接管理与快速重传

**19.1（不定项）关于 TCP 流量控制，下列说法正确的是？**

A. 目标是避免发送方把接收方缓冲区塞爆  
B. 接收方通过 receive window 通告可用缓冲区  
C. 流量控制和拥塞控制关注完全相同的问题  
D. 发送方在途未确认数据量受 rwnd 限制  

答案：A、B、D  
思路：流量控制看接收方，拥塞控制看网络内部。

**19.2（不定项）关于 TCP 连接管理和快速重传，下列说法正确的是？**

A. TCP 三次握手协商并初始化连接状态  
B. 两次握手在存在延迟旧报文时可能出错  
C. 3 个重复 ACK 可触发快速重传  
D. 快速重传必须等待超时后才发生  

答案：A、B、C  
思路：快速重传的目的正是避免等到超时。

### 概念 20：拥塞控制、AIMD、慢启动、CUBIC、ECN 与公平性

**20.1（不定项）关于 TCP 拥塞控制，下列说法正确的是？**

A. cwnd 限制发送方在网络中的未确认数据量  
B. 慢启动阶段 cwnd 每个 RTT 近似翻倍  
C. 拥塞避免阶段 cwnd 每个 RTT 大约增加 1 MSS  
D. AIMD 遇到拥塞信号时加性增大窗口  

答案：A、B、C  
思路：AIMD 是加性增、乘性减；拥塞后应降低速率。

**20.2（不定项）关于现代拥塞控制和 QUIC，下列说法正确的是？**

A. CUBIC 记录丢包时的窗口并以三次函数方式探测带宽  
B. ECN 可让路由器显式标记拥塞而不必直接丢包  
C. 多条 TCP 连接可能让一个应用获得更多带宽份额  
D. QUIC 基于 UDP，并在其上实现可靠性、安全和拥塞控制  

答案：A、B、C、D  
思路：这些都是传输层从 TCP 经典机制继续演化的方向。

## 第四章：网络层数据平面

### 概念 21：网络层服务模型、数据平面与控制平面

**21.1（不定项）关于网络层，下列说法正确的是？**

A. 网络层负责主机到主机交付  
B. IP 提供尽力而为服务  
C. IP 保证分组按序、可靠、低时延到达  
D. 路由器通常检查 IP 头部进行转发  

答案：A、B、D  
思路：Internet IP 层不保证交付、时延、顺序或带宽。

**21.2（不定项）关于数据平面和控制平面，下列说法正确的是？**

A. 数据平面逐包执行查表和转发  
B. 控制平面计算路径、表项和策略  
C. 数据平面通常要求线速处理  
D. 控制平面只存在于应用层，与路由器无关  

答案：A、B、C

**40.5（不定项）关于地址和标识，下列说法正确的是？**

A. 端口号用于标识主机上的进程  
B. IP 地址用于网络层寻址和路由  
C. MAC 地址用于本地链路交付  
D. BGP AS-PATH 用于标识经过的 AS 序列  

答案：A、B、C、D  
思路：不同层有不同粒度的标识：进程、接口/网络位置、本地链路接口、自治系统路径。

**40.6（不定项）关于“表”的作用，下列说法正确的是？**

A. DNS 缓存表保存域名到记录的映射  
B. TCP 连接状态可由四元组区分  
C. 路由器转发表把目的前缀映射到输出接口或下一跳  
D. 以太网交换表把 MAC 地址映射到接口  

答案：A、B、C、D  
思路：网络系统大量依赖映射表，只是每层表项的键和值不同。
