# 《矩阵的奇异值与谱分解》交互博客设计

## 目标

在现有 VitePress 个人站点中新增一篇中文技术学习笔记，用可调节的二维 SVD 实验解释

\[
Ax=U\Sigma V^Tx
\]

的几何含义，并进一步连接奇异值、秩、奇异值谱、秩一展开、严格意义上的谱分解和谱范数。

成品既要能作为一篇独立文章阅读，也要让读者通过调节 SVD 参数直接观察网格、单位圆和向量集合的变化。写作保持简洁、分析性的个人技术笔记风格，不写成教科书式长篇综述。

## 范围

### 包含

- 一篇带 VitePress frontmatter 的中文 Markdown 博客。
- 一个嵌入文章的 Vue 交互实验室。
- 四阶段同步几何图：\(x\)、\(V^Tx\)、\(\Sigma V^Tx\)、\(U\Sigma V^Tx=Ax\)。
- 可调参数 \(\theta_V,\sigma_1,\sigma_2,\theta_U\)，以及正交反射开关。
- 可拖动输入向量 \(x\)、单位圆采样向量和坐标网格。
- 当前二维矩阵的实时谱柱状图。
- 一个独立的高维“谱显微镜”，用 16 根柱展示谱衰减、有效秩和低秩截断。
- 博客目录条目与站点注册。
- 数学辅助函数的自动化测试，以及桌面端和移动端的浏览器验证。

### 不包含

- 用户任意编辑矩阵 \(A\) 的四个元素并反求 SVD。
- 三维矩阵可视化。
- 完整数值线性代数求解器或生产级 SVD 算法实现。
- 外部图片、插画或远程数据依赖。

## 文章结构

### 1. 一个矩阵，三步变换

用一句核心直觉开场：一般线性变换可以拆成“把输入写进右奇异向量基、沿正交方向伸缩、再映射到左奇异向量基”。依次解释：

1. \(V^Tx\) 将 \(x\) 表示到 \(V\) 的正交基中；
2. \(\Sigma\) 沿坐标轴按奇异值伸缩；
3. \(U\) 将结果放入输出空间的正交基。

### 2. SVD 交互实验室

紧接开场放置四阶段同步分镜。读者调节参数时，矩阵、公式、网格、单位圆、向量集和输入向量同时变化。正文在实验之后用一个短例子复盘每一阶段。

### 3. 奇异值、秩与奇异值谱

说明秩只计算非零奇异值的个数，是定性边界；奇异值给出每个方向被保留或压缩的程度，是定量描述。小但非零的奇异值不是信息完全消失，而是该方向区分度变弱、对噪声更敏感。

术语上明确区分：

- 按 \(\sigma_1\ge \sigma_2\ge\cdots\ge0\) 排列得到的是“奇异值谱”或“奇异谱”；
- 单独说矩阵的“谱”通常指特征值集合。

### 4. 从 \(A^TA\) 求出奇异值

对一般实矩阵使用

\[
A^TA=V\Sigma^T\Sigma V^T,
\qquad
A^TAv_i=\sigma_i^2v_i.
\]

在文章的二维方阵实验中，\(\Sigma^T\Sigma=\Sigma^2\)。由 \(A^TA\) 的特征向量得到 \(V\)，由非负特征值平方根得到 \(\sigma_i\)。当 \(\sigma_i>0\) 时，使用

\[
u_i=\frac{Av_i}{\sigma_i}
\]

得到对应的左奇异向量；零奇异值对应的列通过正交补齐。正文会注明：这是理解 SVD 的经典推导路径，实际稳定的数值算法通常不会显式形成 \(A^TA\)，因为它会平方条件数。

### 5. 秩一展开与谱分解

展示一般矩阵的 SVD 秩一展开：

\[
A=\sum_i\sigma_i u_iv_i^T.
\]

随后区分：一般矩阵的上式是奇异值秩一展开；严格意义上的谱分解通常写成对称矩阵的

\[
A=Q\Lambda Q^T.
\]

同时指出 \(A^TA\) 和 \(AA^T\) 本身确实具有谱分解：

\[
A^TA=\sum_i\sigma_i^2v_iv_i^T,
\qquad
AA^T=\sum_i\sigma_i^2u_iu_i^T.
\]

### 6. 谱范数与 Takeaway

用单位圆被映射成椭圆后的最长半轴解释

\[
\lVert A\rVert_2
=\max_{\lVert x\rVert_2=1}\lVert Ax\rVert_2
=\sigma_1.
\]

结尾把几何直觉、信息维度和低秩近似压缩成数条简短结论。

## 主交互实验室

### 参数

- \(\theta_V\)：右奇异向量基的角度，范围 \([-180^\circ,180^\circ]\)。
- \(\sigma_1\)：主奇异值，范围 \([0,3]\)。
- \(\sigma_2\)：次奇异值，范围 \([0,\sigma_1]\)。
- \(\theta_U\)：左奇异向量基的角度，范围 \([-180^\circ,180^\circ]\)。
- \(U\)、\(V\) 各有一个可选反射开关，使实验不限于行列式为正的旋转矩阵。
- 输入向量 \(x\) 可在第一幅图中拖动，也可通过数值输入精调。

约束 \(0\le\sigma_2\le\sigma_1\) 始终成立，避免调节过程中奇异值排序和奇异向量标签突然交换。

### 预设

- 恒等变换：观察四阶段完全重合。
- 各向异性伸缩：突出两个奇异方向的不同尺度。
- 秩一坍缩：令 \(\sigma_2=0\)，观察平面压成直线。
- 近奇异：令 \(\sigma_2\) 很小但非零，连接条件数与数值敏感性。
- 带反射：展示正交矩阵不只包含旋转。

### 四阶段 SVG

四幅图共享同一组基础几何数据，然后分别应用累计矩阵：

1. \(I\)
2. \(V^T\)
3. \(\Sigma V^T\)
4. \(U\Sigma V^T\)

每幅图包含固定坐标轴、变换后的网格、单位圆采样点、采样向量和高亮输入向量。阶段标题、累计公式与当前向量坐标位于图下方。颜色语义固定：蓝色表示 \(V^T\)，橙色表示 \(\Sigma\)，紫色表示 \(U\)。

桌面端显示四列，平板端显示 \(2\times2\)，窄屏手机显示单幅图和可切换的四步标签。图形使用响应式 SVG，以保持高 DPI 清晰度和稳定缩放。

### 当前二维谱

主实验室旁显示两根与 \(\sigma_1,\sigma_2\) 同步的柱，并列出：

- 数值；
- 平方能量占比 \(\sigma_i^2/(\sigma_1^2+\sigma_2^2)\)；
- 精确秩；
- 条件数 \(\kappa_2=\sigma_1/\sigma_2\)，当 \(\sigma_2=0\) 时显示 \(\infty\)。

## 高维谱显微镜

谱显微镜与二维矩阵实验分开标注，避免暗示 16 根柱来自二维 \(A\)。它使用 16 个合成奇异值讲解高维谱形状。

### 谱形预设

- 平坦谱：多个方向尺度接近。
- 慢衰减：信息分散在较多方向。
- 快衰减：少量方向承载主要能量。
- 硬截断：在某个索引后精确为零。

### 控件与反馈

- 衰减参数控制谱的下降速度。
- 阈值 \(\varepsilon\) 控制数值有效秩；阈值以上的柱着色，以下淡化。
- 截断阶数 \(k\) 控制低秩近似 \(A_k\)；前 \(k\) 根柱高亮，尾部谱降低对比度。
- 支持线性和对数纵轴，避免较小奇异值在图中完全不可见。
- 鼠标悬停或键盘聚焦单根柱时，显示索引、\(\sigma_i\)、能量占比与累计能量。
- 实时显示保留能量、有效秩和 Eckart–Young 误差

\[
\lVert A-A_k\rVert_2=\sigma_{k+1}.
\]

## 组件与代码边界

- 博客 Markdown：负责正文、公式、章节顺序和组件挂载。
- `SvdExplorer.vue`：主实验室状态与页面组合。
- `TransformStage.vue`：复用的单阶段响应式 SVG。
- `SpectrumBars.vue`：复用的可访问柱状图，同时服务二维谱和高维谱。
- `SpectrumMicroscope.vue`：高维谱预设、阈值和截断交互。
- `svdMath`：无 UI 的二维矩阵、向量、谱指标和谱预设函数。

组件注册遵循现有 VitePress 主题方式。博客条目加入 `docs/.vitepress/theme/content.ts`，不改动无关导航或现有文章。

## 数据流

1. 参数控件更新单一响应式 SVD 状态。
2. 数学辅助层派生 \(U,V,\Sigma,A\) 和四个累计变换矩阵。
3. 同一派生结果同时驱动 SVG 几何、矩阵显示、向量坐标和二维谱指标。
4. 拖动输入向量只更新 \(x\)，四阶段向量随即重新计算。
5. 高维谱显微镜维护独立状态，只复用谱指标和柱状图组件。

此结构避免图形、数字和公式分别维护导致的不一致。

## 边界情况与可访问性

- \(\sigma_1=\sigma_2=0\) 时，能量占比显示为 0，不进行除零。
- \(\sigma_2=0\) 时条件数明确显示为无穷，页面不显示 `NaN`。
- 参数输入会夹取到合法区间；\(\sigma_1\) 降低时同步收紧 \(\sigma_2\)。
- SVG 拖动使用 Pointer Events 和 pointer capture，并提供数值输入作为键盘替代方式。
- 所有滑杆具有可读标签、当前值和键盘控制。
- 图表不只依赖颜色区分状态，同时使用文字、描边和明暗层级。
- 深色模式使用 VitePress 主题变量；减少动态效果偏好下禁用非必要过渡。
- 服务端渲染阶段不访问 `window` 或 DOM，避免 VitePress 构建失败和 hydration 不一致。

## 视觉方向

- 延续站点现有的简洁技术笔记气质和排版变量。
- 正文保持常规阅读宽度；实验室通过受控的宽屏容器扩展到约 1120px。
- 使用开放式分区和细分隔线，不把每段内容包装成多层卡片。
- 颜色只承担变换阶段和谱状态的语义，不加入装饰性插画、渐变或无关图标。
- 数字使用等宽字体，正文与中文标题沿用站点字体栈。

## 验证策略

### 数学测试

使用 Node 内置测试能力覆盖：

- 旋转和反射矩阵保持正交；
- 四阶段累计结果等于 \(Ax\)；
- \(A^TA=V\Sigma^2V^T\) 在二维构造中成立；
- 零奇异值、条件数和能量占比边界；
- 谱排序、有效秩、累计能量和 \(\sigma_{k+1}\) 截断误差。

不为这些测试引入新的测试框架依赖。

### 构建与浏览器验证

- 运行数学测试和 `npm run docs:build`。
- 在桌面宽度检查四列布局、参数更新、拖动向量、所有预设和反射开关。
- 在移动宽度检查单阶段切换、控件可读性、柱状图标签和横向溢出。
- 检查线性/对数谱、阈值、截断阶数和柱体详情。
- 检查浅色、深色及减少动态效果状态。
- 确认博客索引可进入新文章，文章目录和公式正常渲染。

## 完成标准

- 读者能从四阶段图中辨认 \(V^T\)、\(\Sigma\)、\(U\) 的不同作用。
- 任意合法参数组合下，图形、矩阵和数值保持一致且不出现无效值。
- 秩一坍缩与近奇异预设能直观表达“秩是定性、奇异值是定量”的差异。
- 高维谱柱状图能清楚表达谱衰减、有效秩、累计能量与截断误差。
- 正文准确区分奇异值谱、SVD 秩一展开和严格意义上的谱分解。
- 页面通过构建，并在桌面端和移动端完成核心交互验证。
